# Story: calc-main

As someone doing math on the go, I want a fast scientific calculator with a clear display and all the common functions, so that I can compute expressions without switching apps.

## Acceptance Criteria
- The Calculator shows the current expression and a large live result.
- Scientific functions are available: sin, cos, tan, ln, log, square root, powers, parentheses, pi, e, and factorial.
- An angle-mode indicator (DEG/RAD) is visible.
- The equals key is visually emphasised; AC clears and delete removes the last entry.
- An invalid expression shows a clear "Math Error" message.
