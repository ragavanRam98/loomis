# Story: history-view

As a frequent calculator user, I want to see my past calculations and tap one to reuse it, so that I don't have to retype long expressions.

## Acceptance Criteria
- History lists past calculations, each showing the expression and its result.
- Tapping a history row returns to the Calculator with that calculation reused.
- A "Clear history" action removes all entries.
- When there is no history, a calm empty message is shown.
