# Story: bmi-calc

As a health-conscious user, I want to calculate my BMI from my height and weight, so that I know my healthy weight range.

## Acceptance Criteria
- BMI Calculator has height and weight inputs with sliders and unit toggles.
- It shows a large BMI result with a colored gauge and a category label.
- A healthy weight range is shown for the user's height.
- The back chevron returns to the Dashboard.
