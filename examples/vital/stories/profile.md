# Story: profile

As a user, I want a profile with my stats, achievements, and settings, so that I can manage my account and celebrate progress.

## Acceptance Criteria
- Profile shows my avatar, name, and key stats (streak, total steps, badges).
- Achievements/badges are displayed.
- A settings list covers units, notifications, connected devices, and privacy.
- An "About Vital" row is present.
- The back chevron returns to the Dashboard.
