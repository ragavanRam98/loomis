# Story: goals-track

As a goal-driven user, I want to set and track health goals, so that I stay motivated.

## Acceptance Criteria
- Goals lists goals (steps, calories, water, sleep, weight) each with progress and a target.
- A weekly completion summary is shown.
- A "New goal" action lets me add a goal.
- Completed goals are clearly marked.
- The back chevron returns to the Dashboard.
