# Story: dashboard-overview

As someone tracking my health, I want to open Vital and instantly see today's activity, so that I know how I'm doing without digging.

## Acceptance Criteria
- The Dashboard shows today's steps as a prominent activity ring with a goal.
- Calories burned, distance, and active minutes are visible as stat cards.
- Today's goals show as progress bars.
- A BMI card shows the current value and category and opens the BMI calculator.
- A bottom tab bar gives access to Activity, Goals, and Profile.
